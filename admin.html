📖 30-Day Database Migration Guide

⚠️ Important: Render's free PostgreSQL database expires after 30 days. Follow these steps to keep your data!

🗓️ Timeline

Days 1-25: ✅ All Good - Continue using normally

Days 25-28: ⚠️ Warning - Prepare for backup

Days 28-30: 🔴 Urgent - Export data NOW!

📥 Step 1: Export Your Data (Day 28)

  1. Click the "Backup Now" button above
  2. Click "Export as JSON" (human-readable backup)
  3. Also click "Create Backup Now" (SQL format)
  4. Both files will download to your computer
  5. Save them to: F:\CURSOR BACKUPS\APP RIDES CEL BCKUPS\

🆕 Step 2: Create New Database (Day 29)

  1. Go to Render Dashboard
  2. Click "New +" → "PostgreSQL"
  3. Name: rides-cel-db-2 (or similar)
  4. Region: Oregon (US West)
  5. Plan: FREE
  6. Click "Create Database"
  7. Wait 2-3 minutes for it to be ready

🔗 Step 3: Update Connection (Day 29)

  1. Copy the new database "Internal Database URL"
  2. Go to your web service: ride-request-app
  3. Click "Environment" → "Edit"
  4. Update DATABASE_URL with new connection string
  5. Click "Save Changes"
  6. Render will redeploy automatically (2-3 minutes)

📤 Step 4: Restore Your Data (Day 30)

  1. Open terminal/command prompt on your computer
  2. Navigate to your project folder
  3. Run: node restore-from-backup.js
  4. Or use the SQL file to restore manually
  5. Verify all data appears in admin panel

✅ Step 5: Verify & Clean Up

  1. Login to admin panel
  2. Confirm all ride requests are there
  3. Delete old database from Render (optional, saves clutter)
  4. Reset the 30-day counter (automatic)
  5. Done! You have another 30 days free!

💡 Pro Tips:
• Set a calendar reminder for day 25
• Keep backups in multiple locations (computer + cloud)
• Test the restore process once to feel confident
• Consider upgrading to paid ($7/month) if business is profitable
